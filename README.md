# Spaghetti Network Feedback

This repository is for bug reports, feature requests, and other feedback about **Spaghetti Network**.

Please use the **Issues** tab to submit feedback.

- **Bug report** — Report a problem or unexpected behavior.
- **Feature request or feedback** — Suggest an improvement, request a feature, or share other feedback.

Reports are welcome in **English or Japanese**.

---

# Spaghetti Network フィードバック

このリポジトリでは、**Spaghetti Network** のバグ報告、機能追加・改善の要望、その他のフィードバックを受け付けています。

**Issues** から投稿してください。

- **Bug report / バグ報告** — 不具合や予期しない動作の報告
- **Feature request or feedback / 改善要望・フィードバック** — 機能追加や改善の要望、その他のご意見

報告は **日本語・英語のどちらでも歓迎します**。
